# Kapetan Luke v0.8.2

- Kapetanova naredba: dodirni nevezani brod i upiši Vez 5, Dok 1/2/3, Gat, Istočna obala ili Ponton.
- Brod automatski plovi sigurnom morskom putanjom i poravnava se na odredištu.
- Zapadni vez automatski centrira brod i okreće ga krmom prema obali.
- Ručno vezivanje ostaje dostupno.
- Dugi pritisak i dalje otključava već vezani brod.
- Glasovni pozdrav koristi ime kapetana putem Android Text-to-Speech.
